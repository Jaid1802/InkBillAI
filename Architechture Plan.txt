# Handwriting Engine

This is your core innovation.

Instead of saving only images...

Save every point.

```text
Stroke

↓

Point

↓

x

y

pressure

timestamp

tilt

velocity
```

Example

```json
{
  "strokeId": 21,
  "points": [
    {
      "x": 205,
      "y": 450,
      "pressure": 0.82,
      "time": 1234
    },
    {
      "x": 206,
      "y": 451,
      "pressure": 0.80,
      "time": 1238
    }
  ]
}
```

This allows:

* replay writing
* smoother rendering
* vector scaling
* AI training
* much better recognition
