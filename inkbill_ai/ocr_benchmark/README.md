# OCR/HTR Benchmark Suite

This suite evaluates local ML models for multilingual handwriting recognition, specifically targeting English, Hindi (Devanagari), and Marathi (Devanagari).

## Measured Metrics
- CER (Character Error Rate)
- WER (Word Error Rate)
- Exact Product-name Accuracy
- Numeric Accuracy (Quantity, Rate)
- Inference Latency
- Initialization Time
- Peak RAM Usage

## Models Evaluated
- PaddleOCR PP-OCRv4
- Microsoft TrOCR Small Handwritten
- stepfun-ai/GOT-OCR2_0
